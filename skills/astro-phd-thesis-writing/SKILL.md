# 天文学位论文写作 SOP（硕士 / 博士）

## 0. 目标与硬约束

学位论文不是加长版期刊论文：博士要有系统性（3–5 个互相支撑的工作 + 一条主线），硕士要有完整工作（1–2 个）。产出四份文件：`outline.md`（目录、字数预算、图表清单、创新点）、`format-checklist.md`（学校格式逐条）、各章草稿、`defense/`（答辩 PPT 与问题清单）。

硬规则：格式未确认不排正文；创新点 ≤3 条；不编造学校格式、期刊信息、文献与基金号；不确定项写成"待确认"并问用户；摘要最后写。

## 1. 第一步：锁定格式（不确认不写正文）

逐项确认并写进 `format-checklist.md`：

- **来源版本**：学校 + 院系 + 年份（如"XX 大学研究生院 2024 年修订版"）、学位类型（学术型/专业型）、写作语言（中文/英文 thesis）。
- **版面**：纸张、页边距（上下左右具体值）、页眉页脚、页码位置与起始页（常见摘要用罗马数字、正文用阿拉伯数字）。
- **字体字号**：正文、各级标题、英文与数字字体；行距（固定值或倍数）。
- **编号**：章节 1 / 1.1 / 1.1.1；图与表用"图 2-1"还是"图 2.1"；公式 (2-1)；附录 A.1。
- **摘要**：中文字数与英文对应字数、关键词 3–6 个。
- **参考文献**：GB/T 7714-2015 的顺序编码制或著者-出版年制，或学校自定格式；文献类型标识 [J]/[M]/[D]/[C]/[EB/OL]。
- **其他**：目录深度、致谢是否计入页数、成果表格式、查重率上限、盲审版要求。

用户上传格式文件时，先解析成逐条 checklist 再写作；未上传就列出"待确认清单"，只按 GB/T 7714-2015 与通用规范给默认值，并注明"以你校文件为准"。

## 2. 骨架与字数预算

顺序固定：中英文摘要 → 关键词 → 目录 → 第 1 章 绪论 → 第 2 章 数据与方法 → 第 3 章 结果 → 第 4 章 讨论 → 第 5 章 结论与展望 → 参考文献 → 致谢 → 附录 → 攻读学位期间成果。

- **绪论内部预算**：背景 30%、文献综述 50%、科学问题与创新点 15%、论文结构 5%。
- **总量**（以学校规定为准）：博士 5–8 万字，每章 0.8–1.5 万字；硕士 3–5 万字。
- **主线一句话**：能串起全部章节，如"本文围绕 X 的 Y 问题，用 A/B/C 三类观测逐层约束 Z"。串不起来说明章节该删或该并。
- 每章开头一段写清"本章解决什么问题、承接哪一章、给读者什么"，章末 3–5 句小结；不开头就写数据。

## 3. 创新点（≤3 条）

- 每条 = 数据/方法 + 新结果 + 认识改变，且能被审稿人验证：给出对应章节、图号、数值与误差。
- 不把"综述了某领域""使用了某软件""计算了某物理量"当创新；不与第 1 章综述混写；不在结论里临时加新创新点。
- 博士：三条创新点互相支撑，构成系统；硕士：一条主创新 + 一到两条支撑。
- 模板：`首次利用 [样本/数据] 在 [能段/波段] 检验 [模型]，测得 [量] = [值 ± 误差]，将 [约束/上限] 提高 [N] 倍（或排除 [模型] 至 [置信度]）。` 非首次工作删"首次"，改为"系统检验"或"独立测量"。

## 4. 文献综述

- 组织方式只选一种主结构：按主题（推荐，最接近物理问题）、按时间（仅用于快速演进方向）、按方法（观测 vs 理论）。小节内部可混用。
- 每段 = 一类工作 + 代表文献（原始）+ 结论 + 局限；禁止"张三（2020）研究了……李四（2021）研究了……"的流水账。
- 每个小节末给过渡句，指向尚未解决的问题；综述最后一节列 2–4 个 gap，与创新点一一对应。
- 一手文献优先；中英文文献都要；近 5 年占比不低于 1/3（以领域惯例为准）；不引未读文献、不引二手转述。

## 5. 数据、方法与结果

- **数据**：来源、观测时间、数据版本、样本量、筛选流程（`N → M → K` 每步删多少）、仪器响应与定标。
- **方法**：公式给符号、单位、适用条件；建符号表；误差传播写清；软件给名称与版本；参数取值标出处。
- **结果**：每个结论必须有图或表支撑；统计误差与系统误差分开；显著性说明算法；结果章不解释物理。
- **图表**：编号连续；图注自含；矢量 PDF；色盲友好（Okabe-Ito 或 viridis）；无 gridline、无 3D；缩到最终尺寸后图内字号 ≥8 pt；图题在下、表题在上（按学校要求）。
- **图注模板**：`图 2-1 [物理量] 随 [变量] 的变化。[样本] 按 [判据] 选取；[颜色/线型] 表示 [含义]，阴影为 [1σ/系统] 误差。[一句关键特征]。`

## 6. 讨论

顺序：模型假设与适用范围 → 系统误差与统计误差比较 → 与文献一致或冲突（给数值与条件）→ 物理机制 → 局限 → 可检验预言。

不重复结果、不引入新结果；冲突写"A 报 X，本文得 Y，差异可能来自 Z"；机制叙述可以主动，但每个断言附依据；讨论可单独成章，篇幅按 §2 预算。

## 7. 语言标准

- **中文**：学术书面语；删"其实/然后/基本上/非常/很大程度上/我们觉得"；一句话 ≤40 字，一段 4–8 句；术语首次出现给英文原文与缩写，之后统一。
- **英文摘要**：US 或 UK 统一；背景现在时、方法过去时、结果现在或过去时；与中文摘要结论一致，不逐字直译。
- **术语**：先用 `astro_term_lookup` 核 NADC 审定译名再落笔；同一概念全文只用一个译名；缩写在正文首次定义，摘要中定义的不在正文重复展开。
- **AI 腔清理**：删"综上所述/总而言之/具有重要意义/不仅……而且……"；每段首句必须有信息量；"值得注意的是"每篇最多一次；连接词多样化（然而/因此/相比之下/与此不同）。

## 8. 引用与 GB/T 7714-2015

- 全篇只用一种制式：顺序编码制（正文 [1]、[2-4]）或著者-出版年制（(张三, 2020)）；学校有规定按学校。
- 常见条目：期刊 `作者. 题名[J]. 刊名, 年, 卷(期): 起止页. DOI.`；专著 [M]；学位论文 [D]；会议 [C]；报告 [R]；电子资源 [EB/OL] 给引用日期与 URL。
- 作者 ≤3 全部列出，>3 列前 3 位加"等"（英文 et al.）；英文姓在前、名缩写在后。
- 正文编号与文末一一对应；同一文献只出现一次；删除未引条目；有 DOI 必须给。
- 工具流程：ADS/arXiv/Crossref 导出 BibTeX 或 RIS → EndNote/NoteExpress/Zotero 按学校样式输出 → 手工核对作者、年份、卷期页、文献类型标识。GB/T 7714 没有官方 BibTeX style，用 CSL 或手动校，编译后逐条对 PDF。
- 自引与合作贡献如实写："本章基于已发表工作 [x]，本人负责……"；查重与盲审按学校规定处理。
- 只引与论点直接相关的文献；凑数引用、未读引用、与本文无关的综述一律删。

## 9. 中英文摘要模板

**中文**四段：背景与问题（2–3 句）→ 数据与方法（2–3 句）→ 主要结果（3–5 句，含数字与误差）→ 结论与意义（1–2 句）；关键词 3–6 个。

**英文**（与中文对应但不逐字直译）：

> We present [work] using [data/method]. We measure [quantity] to be [value ± uncertainty], which [constrains/tests] [model]. These results indicate [physics]. [One sentence on implication.]

核对项：中英文数字、样本量、显著性、结论必须一致；英文时态与冠词按 §7 逐句校；缩写首次出现定义。

## 10. 致谢、附录、攻读学位期间成果

- **致谢**：导师、课题组、合作者、基金（编号必须真实）、数据中心与软件；按学校模板措辞；不编造基金号，不替用户决定署名。
- **附录**：长推导、额外图表、数据表、代码说明；正文写"见附录 A"，附录编号与正文引用对应。
- **成果表**：论文/专利/软件按学校格式；只列已发表与已接收，标清状态；作者顺序如实，学生一作与导师一作不混写。

## 11. 查重、盲审、数据可用性与答辩

- **查重**：以学校系统为准；基于已发表章节的要按学校规定标注；引用他人图表需授权或明确注明来源。
- **盲审版**：删作者姓名、导师姓名、致谢、基金号、可识别单位信息；检查 PDF 元数据、文件名、页眉。
- **数据可用性**：给数据仓库 DOI 或"合理请求"声明；软件给版本与链接；公共档案数据写清 release 与检索时间。
- **伦理与合规**：数据与图像使用许可写进正文；生成式 AI 的使用范围按学校要求声明；合作者贡献与作者顺序如实写。
- **答辩 PPT**：10–20 页；1 页创新点；每章 1–2 页核心图；1 页局限与展望；结论与论文完全一致，不出现论文里没有的新结果，图直接复用论文矢量图。
- **预答辩问题清单**：创新点是什么、误差主要来自哪里、与文献值差异如何解释、样本是否有选择偏差、下一步怎么做。

## 12. 修订与导师反馈闭环

- 建意见表：意见 → 位置（章/节/页）→ 改法 → 状态；每改一处回读上下文，防止引入新矛盾。
- **结构**：章首与章末呼应；主线一句话能串起各章；删掉不服务主线的段落；综述 gap 与创新点逐条对齐。
- **语言**：逐段删重复；连接词多样化；数字与单位统一（10¹² eV、5σ、3.2 ± 0.1）；同一术语只用一个写法。
- **格式**：用学校模板样式，不手工调字体；更新目录后核对页码；图表与公式编号连续；提交前全文搜索"TODO/待补/XXX"，检查交叉引用可点击。

## 13. 质量门禁（12 条）

1. 格式逐条对照学校文件，无手工凑的样式。
2. 创新点 ≤3 条，可验证，且与章节、图表对应。
3. 综述有明确 gap，与创新点一一对应。
4. "主线一句话"成立，各章围绕它。
5. 每章有导入段与小结。
6. 每个结论有图/表/公式支撑。
7. 统计误差与系统误差齐全，显著性算法写清。
8. 中英文摘要的数字、样本量、结论一致。
9. 正文引用与文末条目一一对应，GB/T 7714 格式统一。
10. 图表编号连续、图注自含、色盲友好、无 grid。
11. 术语全文统一（NADC 审定译名），缩写首次定义。
12. 无 AI 腔与口语化，数字与单位写法一致。

## 14. 工具映射与执行顺序

- **现有工具**：`astro_term_lookup` 核术语译名；`astro_term_save` 存定稿术语并导出术语表；`astro_term_list` 检查全文用词是否统一；`astro_literature_search` 找综述与一手文献；`astro_literature_analyze` 拆范文与结构；`astro_dictionary` 断网兜底。
- **格式与引用工具**：`astro_format_library`（高校格式/年份版本/GB 7714）、`astro_reference_save/list/update/cite/export`（BibTeX/APA/GB 7714/MLA + `.bib`）、`astro_writing_project`/`astro_writing_handoff`（项目、文件、分析/大纲/逐节起草/格式检查）。工具不可用时按 §8、§12 手动执行，并说明降级。
- **执行顺序**：格式 checklist → 目录与字数预算 → 综述 → 各章 → 摘要（最后）→ 引用与格式 → 盲审版 → 答辩。
- **知网**：只给人工检索链接，不抓取、不绕过登录与付费墙。
