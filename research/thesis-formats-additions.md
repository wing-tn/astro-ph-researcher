## 1. 方法

- 环境：WSL2 + `curl 8.5.0`（GET、`-L`、浏览器 UA），`python3 3.12.3` 解析 HTML；GXU 2026 PDF 用 Ghostscript `txtwrite` 提取正文。
- 先发现候选页（web_search / Sogou 仅作 URL 发现），再对每个官方 URL 实测 HTTP 状态、Content-Type、字节数；附件直链与页面分别记录。
- 判定：页面 HTTP 200 且标题/正文可确认版本 → `verified=true`；只有列表条目而正文需权限、或附件被验证码拦截且无替代 → `verified=false` 或注明限制。
