## 1. 调研方法

- 环境：WSL2 Ubuntu，`curl 8.5.0`、`python3 3.12.3`；GET + `-L` + 浏览器 User-Agent；记录 HTTP 状态码、Content-Type、字节数。
- 文件解析：PDF 用 Ghostscript `txtwrite` 提取正文，docx 用 Python `zipfile` 解 `word/document.xml`；只摘录要点，不把原文件放入仓库。
- 检索：`web_search` 与 Sogou 仅用于发现候选 URL；所有结论以 WSL 实际访问结果为准。
- 判定：页面/文件 HTTP 200 且正文能确认标题与版本 → `verified=true`；无官方公开页或无法确认 → `verified=false`、`url` 留空、`notes` 写“未找到官方格式页”。

## 5. 使用与维护说明

- 本文件与 `data/thesis-formats.seed.json` 只保存要点摘要与链接，不包含学校格式文件本体。
- `verified=true` 仅表示「2026-10-22 该 URL 可访问且正文能确认标题/版本」，不代表学院当年最新细则；天文/物理学院可能另有补充规定。
- 引用标准存在版本差异：北航、北师大、上交为 GB/T 7714-2015，云南大学为 GB/T 7714-2005，国科大模板写 GB/T 7714-2025，中山大学为学校自定格式——使用时以学校最新文件为准。
- JSON 校验：`python3 -m json.tool data/thesis-formats.seed.json`。
