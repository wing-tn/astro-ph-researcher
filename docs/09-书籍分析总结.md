# 09 · 版权清理说明

原「书籍分析总结」页面包含书名、作者、出版社、ISBN、章节结构与原书摘要，存在版权与出版方权益风险。

**已移除以下内容：**

- 书名、作者、出版社、ISBN、页数、定价；
- 原书目录、章节编号、章节摘要；
- 原书引用文本与 BibTeX 条目；
- 数据库中的书籍介绍卡、`book`、`bookRef`、`chapter` 字段。

**保留：**

- 通用天文数据处理方法、统计学原理、公式、假设、步骤；
- 独立编写的 Python 示例；
- 通用技术说明与常见坑。

本插件不再把该教材作为数据源或宣传材料；如作者需要教材级推导，请自行合法获取并核验。
