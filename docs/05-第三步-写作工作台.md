# 第三步：写作工作台

> 版本：v0.3.0
> 目标：把“研究结果 + 参考文献 + 目标期刊/学校格式”组织成 DSH 可以直接执行的写作项目，而不是让模型从零猜。

---

## 1. 工作流

```
创建项目（期刊/学位论文）
  → 选目标期刊或高校格式（年份版本）
  → 上传研究结果文件（可多选；可选是否让 DSH 分析）
  → DSH 分析结果 / 生成大纲
  → 逐节起草
  → 引用与格式检查
  → 导出/复制到 LaTeX/Overleaf 或 Word
```

写作本身由 DSH 按项目提示词执行；工作台负责**上下文、格式、文件、文献与引用**。

---

## 2. 项目模型

```ts
type WritingProject = {
  id: string;
  title: string;
  type: 'journal' | 'thesis';
  language: 'en' | 'zh' | 'bilingual';
  targetId: string;                 // 期刊 id 或高校格式 id
  styleNotes: string;
  outline: string;
  status: string;
  referenceIds: string[];
  files: { name: string; path: string; size: number; type: string; preview?: string }[];
  createdAt: string; updatedAt: string;
};
```

存储：
- `$DSH_HOME/astro-ph-researcher/projects.json`
- `$DSH_HOME/astro-ph-researcher/projects/<id>/files/`

文件上传：
- 文本/CSV/JSON/TeX/Bib 等按 UTF-8 保存并生成 3000 字预览。
- 其他文件按 base64 保存，单文件 ≤8 MB。
- 不把文件内容上传第三方；只有用户选择“交给 DSH 分析”时才进入对话上下文。

## 3. 目标格式库

### 3.1 天文 SCI 期刊

`data/journals.seed.json`（由调研生成，带实测 URL/verified 标记）字段：

```json
{
  "id": "apj",
  "name": "The Astrophysical Journal",
  "abbrev": "ApJ",
  "publisher": "...",
  "scope": "...",
  "homepage": "...",
  "authorGuidelines": "...",
  "overleafTemplate": "...",
  "templateNotes": "...",
  "citationStyle": "...",
  "citationFormat": "...",
  "figureRequirements": "...",
  "language": "en-US",
  "verified": true,
  "verifiedAt": "2026-10-22",
  "notes": ""
}
```

覆盖：ApJ、A&A、RAA、MNRAS、PRL、PRD、JHEAP、CPC、Universe、Nature、Science、AJ、PASP、Nature Astronomy。

使用时：
- 「作者指南」打开官方作者指南；
- 「Overleaf 模板」打开官方/社区模板（未验证会标注）；
- 写作提示词会把期刊 scope、模板、引用风格、图片要求带入。

### 3.2 中国高校学位论文格式

`data/thesis-formats.seed.json` 字段：

```json
{
  "id": "pku-physics",
  "university": "北京大学",
  "department": "物理学院 / 天文系",
  "degree": "博士/硕士",
  "yearVersion": "2023 版",
  "title": "...",
  "url": "官方研究生院/图书馆页面",
  "formatNotes": ["..."],
  "citationStandard": "GB/T 7714-2015 或学校要求",
  "templateUrl": "...",
  "verified": true,
  "verifiedAt": "2026-10-22",
  "notes": ""
}
```

高校名称后必须带年份版本（如“2025 版”），避免格式更新后误用。
找不到官方页面的学校标记 `verified:false`，不编造版本。

### 3.3 用户自定义格式

- 支持粘贴/上传 `.txt/.md/.json/.csv` 格式要求，保存为 `custom` 格式。
- 「导出格式包」生成 JSON；可交给其他人「导入格式包」。
- 当前版本没有云端账户/服务器同步；“云端共享”通过导出文件 + 共享实现，后续可接对象存储或社区索引。

### 3.4 从官方页抓取 / 作者上传格式材料

没有服务器也能工作：**宿主侧**（用户本机 DSH 进程）负责访问官方页、下载文件、解析文本，客户端只展示结果。

- 选中高校/中科院院所后，客户端先检查本地 workspace；没有则**自动**抓取官方页/模板（也可点「搜索并下载官方最新格式/模板」重试）。
- 宿主读取 `thesis-formats.seed.json` 里的 `url` / `templateUrl`，抓取页面并提取 `.pdf/.doc/.docx/.zip` 或附件链接；最多下载 6 个，单文件上限 25 MB。
- 保存到 `%USERPROFILE%\.dsh\astro-ph-researcher\formats\<formatId>\downloads\`，`manifest.json` 记录来源、时间、HTTP/解析结果、sha256。
- DOCX/TXT/MD/HTML/ZIP 内置解析：DOCX 读 `word/document.xml`，ZIP 里找 DOCX；PDF/DOC/WPS/RTF 标记 `needsDsh`，提示用 DSH 的 PDF 阅读/转录能力。
- 支持作者自己上传 `.pdf/.doc/.docx/.zip/.txt/.md/.html`；解析结果与文件路径进入写作提示词。
- 「交给 DSH 解析/使用这份格式」会把文件路径、已解析文本、未完成项一起交给 DSH；不会假装已经读过 PDF。
- 限制：验证码/登录/权限页不会绕过；找不到可下载文件时保留官方页文本并提示用户上传。

## 4. 写作交接模式

`astro_writing_handoff` / `POST /writing/handoff` 支持四种模式：

| mode | 用途 | 输出 |
|---|---|---|
| `analyze` | 分析上传的研究结果 | 数据/样本、仪器/波段、方法、关键结果、误差、局限、可复现性、图表清单、补做分析 |
| `outline` | 先框架后写作 | 3-5 个候选标题、摘要骨架、关键词、章节大纲与字数、图表清单、需补文献 |
| `draft` | 逐节起草 | 按已确认大纲写标题/摘要/引言/方法/结果/讨论/结论；每节自检引用与数字 |
| `format` | 格式检查 | 目标期刊/学校格式清单，当前项目缺什么 |

提示词包含：
- 项目标题/类型/语言/风格要求；
- 目标期刊（作者指南、Overleaf 模板、引用风格）或高校格式（版本、规范链接、GB 7714）；
- 上传文件列表与文本预览（二进制只给元数据）；
- 文献库最多 40 条（标题/期刊/年份/DOI/总结）；
- 严格约束：只用已提供材料，缺失标“文件未提供”，不编造数据/DOI/引用。

## 5. 写作规范（与八个 skill 一致）

详见 `skills/astro-english-journal-writing` 与 `skills/astro-phd-thesis-writing`。工作台只做“把材料和格式喂给 DSH”，不替代 skill 的写作 SOP。

核心要求：
- 英文期刊：US/UK 母语者书面学术英语；标题具体；摘要按“领域/问题 → 方法/源/信使/波段 → 创新性 → 主要结果/数据 → 结论”；关键词按领域/望远镜/方法/源类型排序；Introduction 引原始第一文献；方法可复现；结果与图表一致；结论给物理诠释。
- 学位论文：先确认学校+院系+年份版本；GB/T 7714-2015 或学校要求；章节骨架/字数预算；≤3 条可验证创新点；主题式综述指出 gap；查重/盲审/答辩。
- 图表：PDF 矢量（Overleaf）、色盲友好、无背景 grid、字号足够、图注自含、正文与图表一致。
- 修订：先框架后写作；写完返回检查；避免 AI 套话、重复连接词、每段固定四五行；引用编号与文末一致。

## 6. API 与工具

工具：
- `astro_writing_project`：list/create/get/update/upload_files
- `astro_writing_handoff`：返回写作提示词（不直接注入对话）
- `astro_format_library`：journals/thesis/add_thesis
- `astro_thesis_format`：status/fetch/upload 学位论文格式/模板；抓取到本地并解析，PDF/DOC 标记 needsDsh

- `GET/POST /api/astro-ph-researcher/writing/projects`
- `GET/PATCH/DELETE /api/astro-ph-researcher/writing/projects/:id`
- `POST /api/astro-ph-researcher/writing/projects/:id/files`
- `POST /api/astro-ph-researcher/writing/handoff`
- `GET /api/astro-ph-researcher/writing/meta`
- `POST /api/astro-ph-researcher/writing/thesis-formats/custom`
- `GET /api/astro-ph-researcher/writing/thesis-formats/:id/workspace`

## 7. 边界与后续

当前版本：
- 不自动生成完整论文；由 DSH 按项目提示词与 skill 写作，用户审阅。
- 不解析 PDF/DOCX 格式文件的正文；只读取文本类格式要求。PDF/DOCX 可先转文本或粘贴要点。
- 不直接操作 Overleaf 账号；只给模板链接与 `.bib` 导出。
- 不提供云端同步；格式包通过文件共享。
- 期刊/高校数据由调研生成，`verified:false` 的条目需用户确认。
