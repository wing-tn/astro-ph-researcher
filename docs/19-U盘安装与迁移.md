# 19 · U 盘安装与迁移

> 结论：**可以带到别的电脑用，但它是“插件源码包”，不是免安装的单文件程序。**  
> 目标电脑必须先有 DSH（或 Codex）。

## 1. U 盘里带什么

带这个文件就够：

```text
astro-ph-researcher-3.2.0.zip
SHA256SUMS
```

不要带：

- `.venv/`、`node_modules/`：与路径、平台绑定，复制过去容易坏；
- `provenance/raw/`：含个人会话/本机路径；
- 你的 `terms.json`、`references.json`、`projects/`：除非你想迁移个人数据。

## 2. 目标电脑前置

- Windows（本包主要在 Windows 验证）；
- 已安装 DSH 桌面版（版本需兼容当前插件）；
- 不需要全局 Node/npm；DSH 自带运行时；
- 不需要 Python 才能使用插件（测试/构建脚本才用 Python）。

## 3. 安装步骤

1. 把 zip 解压到固定目录，例如：
   ```text
   D:\astro-ph-researcher-2.0
   ```
2. 在该目录打开 PowerShell：
   ```powershell
   node scripts/install-local.mjs
   ```
   或：
   ```powershell
   dsh plugin --profile desktop add "D:\astro-ph-researcher-2.0"
   ```
3. 完全退出并重启 DSH。
4. 侧栏应出现「天文术语」；设置页显示 `astro-ph-researcher v3.2.0`。

> `install-local.mjs` 会在目标 profile 的 `node_modules` 下建 junction（失败则复制），并把 `astro-ph-researcher` 加入 `dsh.profile.bundles`。

## 4. 迁移个人数据（可选）

插件数据默认在：

```text
C:\Users\<你>\.dsh\astro-ph-researcher\
```

要带走术语本/文献库/写作项目：

1. 在旧机关闭 DSH；
2. 复制整个 `astro-ph-researcher` 文件夹到 U 盘；
3. 在新机放到同路径；
4. 再启动 DSH。

**注意**：这些数据未加密；U 盘丢失会泄露个人文献/项目。建议 BitLocker/VeraCrypt 加密 U 盘，或只复制必要文件。

## 5. Codex 版

`codex/` 是独立 Codex 插件；目标机需安装 Codex CLI：

```bash
cd astro-ph-researcher-2.0
codex plugin marketplace add .
codex plugin add astro-ph-researcher@astro-ph-researcher-local
```

## 6. 校验

```powershell
certutil -hashfile astro-ph-researcher-3.2.0.zip SHA256
```

与 `dist/SHA256SUMS` 对比。

## 7. 不能保证的事

- 不保证所有 DSH 版本兼容（插件依赖 Cordis/DSH 客户端接口）；
- 不保证 Windows 以外的 junction 行为一致（macOS/Linux 用 `dsh plugin add`）；
- 不保证离线可用全部功能：术语核验、文献检索、格式抓取需要网络；
- 插件不是杀毒软件；U 盘文件在目标机应先杀毒/校验来源。
