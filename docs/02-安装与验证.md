# 安装与验证

本文只讲 `F:\dsh插件\astro-words` 这份本地插件的安装、验证与排障。插件尚未发布到 npm。

---

## 1. 确认 DSH 版本与 profile

- 本工作区在 **DSH 桌面版**（DeepSeek Harness，2026-10 构建）上验证。
- profile 目录：`%USERPROFILE%\.dsh\profiles\desktop`
  - 如果你的版本用 `web`，把下文 `desktop` 换成 `web`。
- 插件目录必须保留完整结构：`package.json`、`cordis.patch.yml`、`lib/`、`data/`、`docs/`。

---

## 2. 安装方式 A：DSH CLI（推荐）

在 **Windows PowerShell** 中：

```powershell
& "E:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "F:\dsh插件\astro-words"
```

- 该命令把本地目录加入 profile（DSH 对本地路径通常使用 `link:` 协议）。
- 如果它把目录复制进 `node_modules` 而不是链接，改用：

```powershell
& "E:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "link:F:\dsh插件\astro-words"
```

- 安装后检查 `%USERPROFILE%\.dsh\profiles\desktop\package.json` 的 `dsh.profile.bundles` 是否包含 `astro-ph-researcher`；若没有，按第 3 节手动加入。
- **当前版本实测可热加载**；若侧栏没有出现「天文术语」，刷新页面；仍没有则完全退出并重启 DSH。
- 重启后侧边栏底部出现「天文术语」按钮。

如果提示找不到 `dsh.cmd`，先确认 DSH 安装目录：

```powershell
Test-Path "E:\DSH\resources\runtime\cli\bin\dsh.cmd"
```

---

## 3. 安装方式 B：手动编辑 profile（CLI 不可用）

编辑：

```
%USERPROFILE%\.dsh\profiles\desktop\package.json
```

1. `dependencies` 增加：

```json
"astro-ph-researcher": "link:F:\\dsh插件\\astro-ph-researcher"
```

2. `dsh.profile.bundles` 数组末尾增加：

```json
"astro-ph-researcher"
```

3. 在 `%USERPROFILE%\.dsh\profiles\desktop` 下执行：

```powershell
npm install
```

4. 重启 DSH。

> 不要直接复制 `node_modules`；CLI 方式用 `link:` 依赖让 DSH 读取工作区源码，便于迭代。若 CLI 的路径解析异常，用下面的脚本方式（junction 或复制）。

---

## 3b. 安装方式 C：本地脚本（CLI 路径解析异常时）

如果 CLI 把 `F:\...` 误解析成 `/mnt/f/...`（WSL 下实测遇到过），在 Windows PowerShell 中用仓库脚本：

```powershell
cd "F:\dsh插件\astro-words"
node scripts/install-local.mjs
```

脚本会：
1. 在 `%USERPROFILE%\.dsh\profiles\desktop\node_modules\astro-ph-researcher` 建 junction（失败则复制）；
2. 把 `astro-ph-researcher` 追加到 `dsh.profile.bundles`；
3. 备份 `package.json`。

卸载：

```powershell
node scripts/install-local.mjs --remove
```

## 4. 验证清单

### 4.1 客户端

- [ ] 左侧栏底部出现「天文术语」按钮（轨道图标）。
- [ ] 点击打开浮窗，标题为「天文术语工作台」。
- [ ] 设置页显示 `astro-ph-researcher v1.0.0`，并显示数据目录 `…\.dsh\astro-ph-researcher`。

### 4.2 查词

- [ ] 输入 `redshift` → 中文名「红移」，NADC 词条 #16171，状态「已出版」，可点击打开。
- [ ] 输入 `红移` → 反查到 `redshift`。
- [ ] 输入 `引力透镜` → 「引力透镜（gravitational lens）」，相关词含「引力透镜效应」「微引力透镜」「强引力透镜」。
- [ ] 输入 `gravitational lensing` → 「引力透镜效应」，并出现「同名词条 / 其他译名」（如 gravitational lensing effect）。
- [ ] 点「保存到术语本」→ 术语本出现该条；重启 DSH 后仍在。

### 4.3 文献

- [ ] 输入 `gravitational lensing galaxy clusters` → 返回 ≥3 条，含 DOI/ADS/arXiv/Scholar 链接。
- [ ] 切换「最新」「高引」「相关」→ 顺序变化。
- [ ] 勾选两篇 → 「交给 DSH 分析所选」→ 主对话出现分析请求。
- [ ] 无活跃对话时点击 → 提示词复制到剪贴板。

### 4.4 工具（对话内）

在 DSH 对话中依次问：

1. 「redshift 的中文名是什么？给出 NADC 链接。」→ 应调用 `astro_term_lookup`。
2. 「帮我找 gravitational lensing 的综述，按相关性排序。」→ 应调用 `astro_literature_search`，参数 `sort=balanced` 或 `relevance`。
3. 「把上面两篇整理成分析包，面向研究生。」→ 应调用 `astro_literature_analyze`。

### 4.5 知网

- 文献页底部输入中文关键词 → 「知网搜索」应在浏览器打开 `search.cnki.com.cn` 检索页；「知网总库」打开 `kns.cnki.net`（可能触发滑块）。
- 预期需要机构登录；插件不会抓取内容。

### 4.6 离线词表

- 设置页「官方离线词表」→ 点「下载官方词表」。
- 成功应显示 `r241020 · 31758 条`，并出现「已安装」。
- 断网/NADC 超时后查一个冷门词（如 `2dFGRS`）应返回“离线词表”标记，而不是直接失败。
- 词表文件位于 `%USERPROFILE%\.dsh\astro-ph-researcher\astrodict-dictionary.json`（约 4.5 MB）。

### 4.7 参考文献库

- 文献页保存 1-2 条结果 → 文献库出现条目，含前三位作者、单位、期刊卷期页、DOI/SciX/ADS/arXiv。
- 编辑领域/关键词/专题 → 保存后筛选生效。
- 选 BibTeX → 复制；导出 `.bib` 能被 Overleaf 识别。
- 重启 DSH 后条目仍在（`references.json`）。

### 4.8 写作工作台与 skill

- 新建写作项目（期刊/学位论文），选目标期刊或高校格式；目标链接可打开。
- 上传一个 `.csv` 文本文件 → 项目显示文件与预览；勾选“上传后分析”会向当前对话注入分析请求。
- 「生成写作大纲」「逐节起草」「检查格式」可注入对应提示词；无活跃对话时提示词复制到剪贴板。
- 格式库显示 14 个期刊、21 个高校/中科院院所；可保存自定义格式、导出/导入 JSON 格式包。
- 技能目录应出现 `astro-literature-research`、`astro-code-writing`、`astro-english-journal-writing`、`astro-phd-thesis-writing`。

### 4.9 数据处理与观测设备

- 「数据」页显示 34 方法与 9 条统计；不显示书名/作者/出版社/ISBN/章节。
- 搜索「最小二乘 / Lomb–Scargle / MCMC」→ 展开有公式、步骤与 Python 示例。
- 「观测设备/数据」→ 搜索 Chandra/Fermi/IceCube/FAST → 看到官方数据/分析链接、软件、工作流与政策。
- 按状态筛选：运行中/在建/规划/提案；按政策筛选：开放/受限/专有期/闭源。
- 保存一个设施工作流 → 「我的工作流」出现；删除正常。
- 「交给 DSH 设计/检查流程」会把设施与链接注入当前对话。

### 4.10 学位论文格式抓取 / 上传解析

1. 新建一个「学位论文」项目，选择广西大学/UCAS 等目标。
2. 选中项目后客户端会自动检查/抓取；也可点「搜索并下载官方最新格式/模板」重试。应看到来源、文件数、PDF/DOC 标记“需 DSH 解析”，DOCX/TXT 显示解析文本。
3. 本地路径：`%USERPROFILE%\.dsh\astro-ph-researcher\formats\<formatId>\`；`manifest.json` 记录 `sourceUrl`、`fetchedAt`、sha256。
4. 点「交给 DSH 解析/使用这份格式」：写作提示词应包含文件路径与已解析文本。
5. 自己上传一个 `.txt` 或 `.docx` 格式文件：应显示“已上传并解析”；PDF 显示 needsDsh，不假装已读。

## 5. 排障

### 5.1 侧边栏没有按钮

1. 确认 profile `package.json` 的 `dsh.profile.bundles` 含 `astro-ph-researcher`。
2. 确认 `%USERPROFILE%\.dsh\profiles\desktop\node_modules\astro-ph-researcher` 存在（`link:` 会创建符号链接/junction）。
3. 重启 DSH（不是刷新页面）。
4. 打开 DevTools Console，搜索 `[astro-ph-researcher]`：
   - `client ready` 表示客户端加载；
   - `slots service unavailable` 表示 slot 服务不可用（版本不匹配）。

### 5.2 浮窗报“无法连接本地天文插件服务”

- Host 端未加载：重启 DSH；检查日志中 `[astro-ph-researcher] host ready v1.0.0`。
- 端口/路由被拦截：确认访问的是 `127.0.0.1`，不是局域网地址。
- 路由只接受 loopback；远程 DSH 场景需要改 `isLoopbackRequest`（不建议默认放开）。

### 5.3 查词很慢或超时

- NADC 是公共网页，首次查询 1–3 秒；重复查询命中 24h 缓存。
- 若超时：工具会自动回退本地词表；UI 显示“本地词表（离线）”。
- 不要提高并发；插件已做 350ms 限速，避免给 NADC 压力。

### 5.4 文献结果为空

- 中文检索词未在 NADC 命中时不会硬翻译；先查词取得英文名。
- OpenAlex 免费额度按 IP 共享（约 $0.10/天，检索约 $0.001/次）；如果报 401：
  1. 设置页填 `mailto`；
  2. 或申请免费 key（<https://openalex.org/settings/api>，约 $1/天）并设置环境变量 `OPENALEX_API_KEY`；
  3. 或临时切换 `source=crossref`。
- 年份/最低被引过滤太严也会为空；放宽后重试。

### 5.4b 离线词表下载失败

- 官方 zip 约 696 KB，网络慢时可能超 60 秒；重试即可。
- 若提示“dictionary archive does not contain _ec.txt / _ce.txt”，说明官方包结构变化；先继续用在线查词，并反馈该错误。
- 词表文件损坏时可直接删除 `%USERPROFILE%\.dsh\astro-ph-researcher\astrodict-dictionary.json`，重启后重新下载。
- 插件不会把词表打进发行物；每次下载都从 `nadc.china-vo.org` 获取。

### 5.5 ADS 不可用

- 申请 token：<https://ui.adsabs.harvard.edu/user/settings/token>
- 只通过环境变量提供，不写入配置文件：

```powershell
$env:ADS_API_TOKEN = "your-token"
```

- 设置后重启 DSH；设置页显示「ADS 可用」。
- 无 token 时自动回退 OpenAlex，引用数口径会不同。

### 5.6 OpenAlex key（可选）

- 无 key 时免费额度按 IP 共享，约 $0.10/天；检索约 $0.001/次。
- 申请免费 key：<https://openalex.org/settings/api>（约 $1/天）。
- 只通过环境变量提供：

```powershell
$env:OPENALEX_API_KEY = "your-key"
```

- 不配置也能用；额度耗尽（HTTP 401）时自动回退 Crossref。

### 5.7 知网打不开/要登录

- 预期行为。知网没有公开 API，学位论文需要机构权限。
- `kns.cnki.net` 全站 `Disallow` 且首请求常触发滑块验证；插件把它作为“知网总库”第二按钮。
- `search.cnki.com.cn` 通常可直接打开，但结果是前端 JS 渲染，插件不抓取。
- 可先在浏览器登录学校图书馆/CNKI，再打开插件给的深链。
- 后续版本计划支持“粘贴 CNKI 导出题录 → 解析”，不做抓取。

## 6. 卸载

```powershell
& "E:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove astro-ph-researcher
```

数据目录不会被删除：

```
%USERPROFILE%\.dsh\astro-ph-researcher\
├─ terms.json
└─ config.json
```

需要彻底清理时手动删除该目录。

## 8. 版本兼容

- 依赖宿主服务：`webServer`、`tools`、`systemPrompt`、`slots`、`agents`。
- 使用 `sidebar.footer.action` 与 `shell.overlay` 两个稳定 slot；不依赖可选的右侧栏。
- 若未来 DSH 移除 `sidebar.footer.action`，可迁移到 `settings.section`（功能不丢，入口变化）。
