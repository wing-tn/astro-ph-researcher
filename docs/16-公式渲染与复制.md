# 16 · 公式：LaTeX 渲染与复制

> 版本：v1.0.1（2026-10-22）  
> 目标：公式在插件里以**编译后的数学形式**显示，同时永远提供**可粘贴的 LaTeX 源码**。

---

## 1. 显示方式

- 使用本地 **KaTeX 0.16.22**（MIT，随插件分发，不走 CDN）。
- 资源路径：`assets/katex/`，由宿主路由提供：
  ```text
  /api/astro-ph-researcher/assets/katex/katex.min.js
  /api/astro-ph-researcher/assets/katex/katex.min.css
  /api/astro-ph-researcher/assets/katex/fonts/*.woff2
  ```
- 客户端第一次需要显示公式时动态加载；加载失败时显示**原始 LaTeX**，不会空白。
- 每个公式卡片都有：
  - `复制 LaTeX`；
  - `查看/粘贴 LaTeX`，展开后可选中源码；
  - 编译后的公式本身。

---

## 2. 数据字段

方法/统计条目新增：

```json
{
  "formula": "人类可读的说明/旧公式文本",
  "formulaLatex": "I_{\\mathrm{cal}}=\\frac{I_{\\mathrm{raw}}-B}{F}"
}
```

规则：

- `formulaLatex` 只放**纯数学**，中文解释放 `formula`/`statement`/`assumptions`；
- 不要在 `formulaLatex` 里写大段中文；KaTeX 的 CJK 支持有限；
- 复杂公式可用 `aligned`、`\begin{aligned}...\end{aligned}`；
- 不要把未编译的 LaTeX 当唯一内容：必须能复制。

宿主工具 `astro_data_method` 同时输出：

```text
公式：<人类可读>
LaTeX（可粘贴）：`<源码>`
```

---

## 3. 客户端行为

- 组件：`Formula`；
- 依赖：`window.katex`（本地脚本加载）；
- 渲染：`katex.renderToString(latex, { displayMode: true, throwOnError: false, strict: 'ignore', trust: false })`；
- 复制：`navigator.clipboard.writeText`，失败时回退到 `textarea + execCommand`；
- 折叠源码：`<details>`，不占版面；
- 加载失败：显示等宽字体源码，仍可复制。

---

## 4. 安全与边界

- KaTeX 使用 `trust: false`，不执行 `\href`/`\html` 等危险命令；
- 宿主静态路由只服务 `assets/katex/`，拒绝 `..` 路径穿越；
- 不加载远程脚本/字体；没有网络也能显示；
- 不渲染用户上传的任意 HTML；只渲染 `formulaLatex` 字符串；
- 公式是排版，不是物理正确性的证明；物理检查仍走 v2 的书目/守则/作者确认。

## 7. 已知限制

- KaTeX 不覆盖所有 LaTeX 宏包；复杂排版（TikZ、algorithm2e）不支持；
- CJK 字符在公式中依赖字体，尽量把中文放到说明文字；
- 当前只覆盖方法/统计公式；术语公式后续迁移；
- 需要重启 DSH 才能让新 host 静态资源路由生效（客户端刷新不够）。
